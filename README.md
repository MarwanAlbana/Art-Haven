# Art Haven

## ملفات المشروع
- `index.html`: هيكل الموقع ومحتواه.
- `style.css`: التصميم الأصلي والتنسيقات والحركات والوضع الليلي.
- `script.js`: وظائف الموقع والتفاعلات الجديدة.

## التشغيل
ارفع الملفات الثلاثة في نفس المجلد على GitHub، مع الحفاظ على أسمائها كما هي.
فعّل GitHub Pages من Settings → Pages، واختر الفرع الرئيسي ومجلد الجذر (root).

ملاحظة: الصور والخطوط التي يستخدمها الموقع قد تعتمد على مصادر خارجية موجودة أصلًا في الكود.
